# TuTeMeMe site

Public pages for the TuTeMeMe app (privacy policy and support), served by GitHub Pages. Nothing else lives here; the app's code is in the private `antargyan/TuTeMeMe` repo.

`privacy/index.html` is generated from `PRIVACY.md` in that repo. When the policy changes there, regenerate this page (GitHub's markdown renderer, same layout) and bump "Last updated".
